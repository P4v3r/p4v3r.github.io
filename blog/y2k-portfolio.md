# Building a Y2K Portfolio in 2026

*Published: April 23, 2026*

---

Nostalgia is a powerful thing. While the world moves towards React apps, Tailwind CSS, and AI-generated minimalist designs with glass morphism and 50 shades of gray... I decided to build a portfolio like it's 1999.

## Why Y2K?

The aesthetic from 1999-2003 represents something special:

- **Authenticity** - No algorithms, no engagement farming, just personal expression
- **Creativity** - People made COOL things with tables, marquees, and animated GIFs
- **Personality** - Every site was different, every site was YOU
- **Playfulness** - The internet was fun, not optimized

Today, every website looks the same. SaaS landing pages: hero section, features grid, testimonials, pricing, CTA. Same layout, different gradient.

## The Vibe

Mixing:
- Cyber/Vaporwave aesthetics (gradients, neon, glitch)
- MTV/Skater 90s (colorsplash, bold type)
- Anime 90s (dynamic shapes, saturated colors)
- Classic web (marquee, hit counters, "under construction")

And putting it all together with `<table>` layouts like god intended.

## Technical Decisions

1. **No frameworks** - Pure HTML/CSS/JS, like 1999
2. **No build step** - GitHub Pages serves directly
3. **Config-driven** - JSON files for content, easy to update
4. **Scanline effects** - CSS only, no images
5. **Marquee everywhere** - Because why not

## The Result

A site that:
- Loads fast (no JS bloat)
- Works everywhere (static HTML)
- Feels unique (not another React SPA)
- Has personality (pure Y2K energy)
